# MyBlog: Django CMS

A personal blog with a full content management system built with Django.

## Features
- Rich-text editor (CKEditor)
- Draft / Publish / Schedule workflow
- Categories, tags and author profiles
- Comment system with moderation queue
- Email subscription for new posts
- RSS/Atom feed and sitemap
- Visitor counter middleware

## Tech Stack
Python, Django, SQLite, django-taggit, django-ckeditor
